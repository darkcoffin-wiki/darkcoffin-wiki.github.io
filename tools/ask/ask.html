问答搜索

上面搜索，下面问答，两块互不影响。 搜索免费、不需要 API key；AI 的两个入口（「用 AI 解释这些结果」和下方对话框） 需要你自己的 DeepSeek API key，只填一次、两处共用。

怎么用比较好

  • 只是找原文：用上面的搜索，不需要任何配置。输入「希联」「北沙」「四季常村」这类名词命中率最高； 简称和全称互认（希联／希望联邦、进盟／进化者同盟、教团国／启示录教团国）。
  • 想一次看清某个问题的脉络：先搜，再点「用 AI 解释这些结果」。 它会把检索到的原文串起来讲一遍，并标出来源编号；这是一次性的，不占对话。
  • 想追着问：用下面的对话框。直接写整句就行——「希联的意识形态是什么」 「余烬说过什么经典台词」「第九季发生了什么」都可以。
  • 可以追问：接着问「那进盟呢」；换话题时它会自动重置上下文并补查新原文。
  • 它不会编：资料里没有的会直说没有；设定互相矛盾时会标「异说」； 列举类问题（「都有谁」）会说明「以下是检索到的，可能不全」。
  • 关于 key：只存在本页会话里，关闭标签页即失效，不上传、不记录。 一次问答约一两分钱（deepseek-flash，周末半价），对话框底部显示累计估算。

问答搜索

搜索与问答在同一个页面：先搜关键词（或直接问一句话）， 设定集、花絮、 跑团记录、分析报告 会一起列出相关条目；想深挖就点「用 AI 回答这个问题」， 它会读原文作答，回答完还能接着追问。

AI 部分用你自己的 DeepSeek API key：只填一次， 检索和问答共用（key 只存在本页会话里，关掉标签页即失效，不上传、不记录）。 AI 可能出错或遗漏，一切以链接到的原文为准。

怎么问比较好

  • 名词优先：只输入「希联」「北沙」「天使」「镜缘」这类词，命中率最高。
  • 不必写整句：写成自然语言也行，但系统是按关键词匹配的，长句的效果取决于里面有几个实体词。
  • 简称与全称都认：希联／希望联邦、进盟／进化者同盟、教团国／启示录教团国 等会互相当作同义词。
  • 想看原文就点结果——检索本身不生成内容，每个结果都指向 wiki 里的真实页面。
  • AI 问答：点检索结果下方的「用 AI 回答这个问题」，填入你自己的 DeepSeek API key，它会读取相关原文再作答，并给每个结论标注来源编号。回答仅供参考。
  • 追问：回答完可以在下面的输入框接着问（比如「那进盟呢？」）。 换话题时它会自动补查新的原文，并提示「已按新话题重置上下文」。

黑柩问答

就《黑柩》的世界观直接提问，像聊天一样多轮追问。 每次提问它会先从 wiki 里查出最相关的原文，再依据这些原文回答， 并给每个结论标注来源编号；点编号或来源卡片可以核对原文。

用的是你自己的 DeepSeek API key——key 只存在本页会话里， 关掉标签页即失效，不上传、不记录。AI 可能出错或遗漏，一切以链接到的原文为准。

怎么问比较好

  • 直接问整句就行：这里是对话，不是关键词搜索，「希联的意识形态是什么」这类问法很合适。
  • 想查具体词条：用 检索页 更快——它会一次列出四个站里所有相关条目。
  • 可以追问：接着问「那进盟呢」「他在哪一场出现过」都行；换话题时它会自动补查新的原文。
  • 它不会编：资料里没有的，它会直说没有；设定互相矛盾时会标「异说」，不替你圆。
  • 省钱提示：一次问答约一两分钱（deepseek-flash，周末半价）；页底会显示累计估算。

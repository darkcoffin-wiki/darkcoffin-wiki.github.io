六、剧情摘要

（一）顿独自潜行进入医院展厅

顿尝试潜行（骰点成功），"也许成功了的话，不会被黑暗中的某些怪东西发现"，随后顿 潜行+4并悄悄来到医院展厅。他在展厅里不慎踩到一个气球，"嘣！"一声竟把展厅的声控灯全点亮——但那个"似乎能够粉碎一切的怪物却并没有来——周遭反而更加安静了起来"。他因此看到展厅最西边的医院大门。

（二）求救的女孩与门后的黑暗

门突然被推开，门后传来一片光亮。顿尝试接近，过程却"无比缓慢"。门后站着一个红色短发、穿水手服、似乎还在上高中的女孩子，喊："？？：'有人在里面吗？我来救你们了！'" 她自称超能力者，说这是"其他超能力者给你们设计的陷阱，但我会把它破除——"，话音未落，她的肚子"突然被一束'强光剖开'"，只留下"破……除……"两字，随后化成了一张人"皮"，犹如液体一般流在地面上；与此同时光亮化为黑暗，门后是无尽的黑暗。

（三）燕尾服的女人：真理与"送回起点"

顿感到毛骨悚然，发现自己被"凭空托了起来"，且身上除猫耳头饰与铃铛外没什么可扔。他摘下铃铛扔向门后虚空，一个成熟女人的声音传来："蝼蚁，这个铃铛你还是自己拿着吧。"铃铛被弹回，重新挂回顿的项圈。门开了——一个罩着黑色长袍的女人，实则是一件"如长袍一般的燕尾服"，"犹如斗篷一般遮天蔽地，就像恶魔伸出的翅膀"；她把眼睛藏在魔术帽上，只展示"含着讥诮的唇"，手持冒着阴森黑气的黑色法杖，高高浮在空中俯视顿。她将真理与顿的关系反复点明："须知，真理只能由自己触碰。" / "真理，往往并非那么显而易见。" / "显然不是。如果由你来设计一个密室，你会把显而易见的大门设置为出口吗？" / "我唯一能给你的仁慈，就是将你送回起点。" / "万事万物，皆有起始，皆有终焉。" 于是顿 醒了，出现在探视室，发现"探视室还是起初那个样子"。

（四）电视与希联新闻（273年5月5号）

探视室的电视被打开（静静按下电源键，电视竟然亮了；此前它"显示着雪花画面"）。新闻内容被旁白分两次呈现："欢迎观看希联新闻，今天是273年5月5号。首先将播报新的总统大选情况。" ——"一位带着铁制面具的女性参加了大选。她是一位街头演说家，却似乎掌握了许多某些人不想公布出去的秘密。她自称 总统。她说，她以此为名，也以此为目标。" ——"这位自称总统的女士的主张是，将希联的三座城市整合起来，使希联变得更加强大——以应对进盟的威胁。人们苦于城市之间的彼此对立，支持她的人越来越多。她向媒体揭穿了许多高层人士的黑料……接下来是……（新闻结束）"

（五）众人归位与分工的讨论

"于是 大家都回到了探视室（除了静静）"。陆柩表示"等那位新朋友（指静静）回来就知道了。似乎我们还没进过别的房间"，并问"她长什么样子？"。关于分头行动，陆柩提议"要不我们几个都去吧"，原星否决细分："分工虽然好，但分的太细了也很危险。"风薰认可。陆柩还提到"有道理。（好感为52）"，即承接上一场对小智的好感值。

（六）开放病房：三幅铅笔画与一具骷髅

静静在开放病房中央看到数张锈迹斑斑的病床，"只有两张还放着东西——一张靠西，一张靠东"。

- 靠西的床上放着一根铅笔和几幅铅笔画。第一幅笔风最为幼稚，"是一个微笑着的太阳——出现在病床上的窗外"；第二幅"逐渐像个样子"，是医院工作人员的简笔画——护士和医生围着一个孩子微笑着，"虽然他们手中还拿着束缚带"；第三幅是两个人的合影——一个女人和她十几岁的孩子，"两人手牵着手，在阳光下微笑。她们的身后是一家医院，似乎她们正从这里走出去"。
- 静静看到第三幅画时，"突然脑袋里出现了一些画面"："妈妈，我是不是马上就能出院了？"／"镜缘，等院长说你病好了，妈妈马上就带你出院。"／"妈妈，你是不是没有好好吃饭？你瘦了。"／"妈妈都好，妈妈只是想在你出院的时候给你准备一些礼物，所以有点忙……妈妈都好，你放心。" 画面散去，周围没有变化。
- 静静判定被子下的东西"没发出任何声音。至少肯定不是正在运行的机械或者什么活物"，随后掀开了被子——里面是一具骷髅，"似乎……已经放在这被子下面很久了"，其手上还攥着一张红色的请柬。静静 san-2，当前 8/10（旁白同时给出本团 sanity 规则：默认初始 san 为 10，最多可扣到 -10；低于等于 5 触发临时疯狂；低于 0 触发长期疯狂且无法行动）。
- 请柬内容："郎保保：和运昌大人即将于吉日x月x日（模糊）与你的女儿郎泉泉成婚。老来得女，又能得见和大人关照，实在是一桩喜事。出院以后，速来和家，大人要赏你点礼物。" 静静收起了郎保保的请柬。

（七）影碟机与"懂懂"的宣传片

静静发现电视底下的柜子里装着一些影碟；电视是一台 60 寸左右的液晶电视，"虽然没有遥控器，但电源键、音量键之类一应俱全"。她打开影碟机的碟片口，发现里面塞着一张空白封面的碟片，于是将影碟放回碟片口——电视便又自动播放起来：先是"滋滋——滋滋——"，接着"欢迎光临伟大北沙精神病院！我是大家的大明星，懂懂！"——一个长得极其矮小、但似乎已经成年的男人招手，"背景是医院的咨询台，护士和医生们正在走廊里来往"。宣传片带着诡异："懂懂将带大家了解我们的快乐生活！"（有那么一瞬间，他的身影好像被拉长了）"这里是开放病房！大家都很快乐，一切都是共享的，我们之间没有秘密！我们是最快乐的精神病人！"随后："这里是娱乐中心！"（懂懂走上楼梯，旁边的第二封闭病房传来尖叫和殴打声，但他并不在意）"大家都在这里放松身心！""这里是禁闭室！"（铁门一开，里面便出现大量血迹，他赶忙将扭曲的面孔凑向镜头）"大家——（滋滋）只要大家好好表现，就不会进入这里哦！当然，就算大家不——也会——欢迎加入伟大北沙精神病院！"#放映结束 陆柩那句关于静静的问题——"她长什么样子？"——恰在新闻的语境中被抛出，电视随即回到雪花画面。

（八）其他探索：男性封闭病房、电休克手术室、员工办公区

- 小智来到男性封闭病房，门也没锁。他看到的场景：南边窗户透着惨淡的光、窗下似乎掉了什么东西；北边墙边堆着一些束缚带；西边墙上画着一幅宣传画；东边堆着的东西被白色帘子罩住了；"中间——许多病床堆出了一个掩体，似乎在隐藏着什么"。他侦查后确认"没有在这里发现什么其他更怪异的事情。没有埋伏、没有异动"。

七、关键决策点

  1. 顿选择独自潜行前往医院展厅（并踩到气球点亮声控灯）——直接引出超能力女孩与燕尾服女人的遭遇。
  2. 顿摘下铃铛扔向门后虚空——遭到"蝼蚁，这个铃铛你还是自己拿着吧"的回应，铃铛被弹回；此举未能换取任何通行，直接被"送回起点"。
  3. 静静掀开靠东病床的被子——发现骷髅与红色请柬，自身 san-2（当前 8/10），并取得郎保保的请柬。
  4. 静静打开影碟机、将空白封面碟片放回碟片口——触发电视自动播放"懂懂"的北沙精神病院宣传片，暴露娱乐中心、第二封闭病房、禁闭室等信息。
  5. 众人倾向分头探索（小智去男性封闭病房、乙醇去电休克手术室、顿去员工办公区、静静在开放病房），但陆柩提出"要不我们几个都去吧"、原星以"分的太细了也很危险"否决——最终维持分散但保持警惕的安排。
  6. 陆柩主动向神秘能量球喊话并直呼"原绘"——把幕后设计者的名字逼了出来，促成原星确认设计者身份，并引出"天使被屠"的关键情报。
  7. 原星定下"明天大家一起气死她"的挑衅方针，陆柩主张整理原绘资料——玩家侧（三人 NPC 侧）确立了后续的行动基调，风薰表示"看热闹一般不嫌事大"。
  8. 乙醇打开电休克手术室的闭路电视——见到院长影像，院长对其笑了笑、视线不动、三秒后准时关闭。
  9. 小智选择进入男性封闭病房并完成侦查——确认此处无埋伏无异常，但记录了病床掩体、白帘罩物等未解线索。

十一、伏笔／钩子

  • 原绘的身份与动机：超能力者、曾与大公共事设计天使、因天使点评她的戏剧而将那一批次天使全部杀死，理由是"在伦理学上，不合格"——她自称要"将真理更好地展现于此"，并要众人"搞清楚全部的真相"。
  • 郎保保的请柬："和运昌大人即将……与你的女儿郎泉泉成婚"——与第一场文件中郎保保被关入院的时间线相扣，和运昌与郎泉泉均未出场。
  • 靠东病床下的骷髅身份未明；靠西病床的三幅铅笔画与镜缘/母亲的心声指向镜缘的成长期。
  • 院长的闭路电视影像：秃头、锐利眼神、桌上金色"院长"牌，看屏幕三秒后准时关闭——与本场文件、电椅、禁闭室血迹构成一条待查线索。
  • 顿获得的怪物定位能力与"二楼西北角房间"这一未探索坐标。
  • 智波发现的走廊最东边逃生通道（承前场）在本场未被使用；医院展厅最西边的医院大门已被证明是陷阱。
  • 希联新闻（273年5月5号）：铁面具女性自称"总统"、主张整合希联三座城市以应对进盟威胁、揭发高层黑料——与陆柩所说"最近希联都快爆发内战""有人打算把各路豪强聚起来开个会"呼应。
  • "结团"被陆柩解释为"我们这个世界的终焉"；千分这位长期未公开发言却照常运转帮派与公司的穿越者被点名。
  • 叙事／最高叙事者／灵能封闭效应的世界观说明——"有人在我们的世界这篇作品上写了一条注解"，解释此地异能受限。
  • 男性封闭病房"许多病床堆出的掩体，似乎在隐藏着什么"以及东侧被白帘罩住的东西，均未揭开。
  • 电视宣传片提到的第二封闭病房（尖叫与殴打声）与禁闭室（大量血迹），以及镜缘被"已转入第二封闭病房"的记录相互照应。
  • 顿在展厅听女人说"我唯一能给你的仁慈，就是将你送回起点"，与"第一次——之后会有更多次"（前场）同构，暗示循环将重演。

六、剧情摘要

（一）豪华跑车与「四大天王」

- 剧情线导入：乙醇向秘书表达要立刻前往民主党会议的想法，随后乘黑色奢华 roselose 跑车抵达青都市政府，秘书在车门前为他擦去灰尘，他踩上红地毯。
- 旁白补世界观百科：不同势力使用不同纪年，希联临时政府用复国纪年，「以进盟对星都发起的突袭这一年为元年」。
- 门前几位中年男人在交谈：大禾集团（日用品起家，近年涉足金融、教育）、小父游戏公司（推出「小父gamepass」）、富贵集团（房地产商，现在也做互联网、基建、电子设备）。三人互相恭维顶着临时政府平价政策收缩产能、扩大经销网络、提前布局互联网的操作。
- 门前军人分两种制服：红黑相间（希联纠察队）与深灰色。乙醇选择和一名深灰制服士兵搭话，士兵受宠若惊地立正高喊「董事长好！」「忠！忠诚！」，并汇报参会名单（大禾、小父、光胜、富贵的总裁和助理团，中心商业区各企业代表，我党政府部门的官员代表、各行业党员代表）。
- 乙醇走上红毯与三位总裁合影，媒体喊出「四大天王到齐了！」。小夫主动攀谈，把光胜称作「为诸君在最前线阻挡共党的物价政策」，主张会上团结一致「共同阻击共党的不良用心，保护自由市场」；大禾（李大禾）主张和帝国「谈出一个好价钱」；蓝冷泉自陈是富贵集团董事会成员、真正董事长是通雷帮的千分先生。

（二）世界地图与千分入场

- 秘书用无线电把世界地图传进乙醇的 AR 眼镜，并介绍：西南边的夜都就是神圣希望帝国，原本是希联的军队，进盟宣战时独立为一股势力；他们手上有核武器，所以「我们在和他们谈判，准备和平统一希联」。
- 蓝冷泉接着谈复国军问题：「现在复国军里共党肆虐，我党需要恢复基层的工作，才能和共党抗衡。要是内战爆发，从现在的情况来看，我党很危险啊。」又透露自家董事长「听说他与共党有勾结，民主党这边的入党仪式也一直没邀请他」。
- 市政府门前电子海报写着「希望联邦临时政府第三次代表大会暨各党派会议」。千分此时进入乙醇的剧情线——他早早就坐在民主党会议的角落里，那是一个没有名牌的听众席，他戴着口罩没人认出，也没有人在意他。

（三）修宪会议预备会议

- 四位总裁在士兵保护下进入大会场：门上到前台铺着红地毯，两排宪兵队军人守在地毯旁；带桌子和名牌的代表席与只有椅子的听众席都已坐满；大会台上的嘉宾座是四位总裁的座位，面向台下所有人，台下依次坐着政府官员、军方代表、法律界、教育界、宗教界、传媒界、文化界人士。秘书解释这是「为了最大程度地展现我们四大企业在党内的主体地位」。
- 主持人登场：宪兵队执行队长兼民主党党鞭高冒，约四十多岁，胸前挂满勋章。他声明自己「仅维持会议的秩序和流程」，会议效力由各位代表尤其是台上四位首长实现。
- 全体起立奏唱党歌：「自由民主，革新开放，希望联邦迎接希望。」「光荣伟大，国家事业，诸君携手共创辉煌。」「壮哉！民主的栋梁！壮哉！祖国的未来！」「祖国万众团结起来，前进！」
- 官方发言人（青都自由大学金融系青宇教授）宣读纲要：讨论希联共产党、神圣希望帝国、希联复国军的相关方略，并商讨民主党的未来。

（四）三位总裁的发言

- 小夫：抨击共产党上次代表大会通过的物价政策「劳民伤财」，扶贫的人力物力「本应投入生产，却做了这样的无用功」，主张「市场会调节一切」「物价是价值规律的体现，不是政府能够去轻易管理的」，提议联手反对物价政策，高呼「自由民主万岁！」。高冒记为一项议案，之后统一投票。
- 大禾：主张接受神圣希望帝国开出的价码，基础是同意《青都条约》——向帝国提供廉价劳工、廉价出售资源；被取缔的小公司可获「足以一生富贵」的补偿款；换来帝国尊重青都的自治、做到「青人治青」，「把青都打造成祖国的窗口，世界的青都」；再以此宣传、推翻共产党、统一祖国，高呼「祖国万岁！」
- 蓝冷泉（代千分发言，称千分因身体原因未出席）：主攻复国军问题，称共产党在军中搞诉苦大会、发扶贫金、互称同志、开民主集中会，是「暗地里破坏军纪、拉帮结派、诋毁政府」；进而提出「攘外，必先安内」，要「组建一支忠诚于党国的军队」——取缔非法集会、要求军人服从军纪、鼓励举报「威胁临时政府权威的暴论」、大抓狠抓「威胁和平的暴徒」，呼吁舆论攻势、军队动员与政府调查配合，高呼「和平万岁！」
- 乙醇以身体不适为由未作正式讲话（高冒改请蓝冷泉先讲）。

（五）议案与表决

- 议案列表：①反对物价政策和扶贫政策　②签订《青都条约》　③重振复国军，严振军纪，打击不法分子　④罢工合法化，规范化　⑤在宪法中规范议会章程　⑥与黑帮进行政治合作　⑦建立黄色工会，遵从民主党的命令。
- 表决规则：各代表投票共算作七票，四位总裁各算一票；各代表为分类别无记名投票，总裁为实名投票。
- 逐条结果（按政府官员、军方代表、法律、教育、宗教、传媒、文化、小夫、大禾、乙醇、蓝冷泉顺序）：①00210000000 通过　②01022220010 通过　③00022000000 通过　④22000000000 通过　⑤00002000000 通过　⑥10111220202 待议　⑦00000000000 全票通过。
- 最终结果：①②③④⑤⑦通过，⑥「与黑帮进行政治合作」搁置。
- 场内问答：一位小企业家上台陈述——启示录教团国已与帝国签约，帝国正靠教团国的廉价劳动力快速发展，污染与劳力密集产业被转移，帝国境内开始建设高端产业；他凑到乙醇耳边低声说「只要我们能好好过日子，人民群众的事情和我们又有什么关系呢？」又说「帝国和我们本是同根生，统一以后帝国就是我们的国家啦」，随后「看乙醇的眼神恐惧又讶异」地退下。
- 大禾补充《青都条约》的由来：帝国起初要求希联人全体成为二等公民，后来看了复国军阅兵才一点点松口；并警告「如果我们在《青都条约》面前说这说那，帝国打击我们就不远了」。秘书在无线电里补足背景：议会是共产党建的，共产党员与民主党员是全青都唯二的合法党派；天策是最大变数——开发了改变战争局势的武器（灵魂集束武器，可穿透天使护身结界），获民众声望后投奔共产党；叶心是天策公司老板，后成为共产党员；民主党代表团目前全权负责与帝国谈判。

（六）关掉麦克风的交易

- 大禾点破乙醇的态度：「看来您是想使用总裁的一票否决权了？」高冒正声纠正规则：各总裁可以让一个议题回到搁置状态，「这不叫一票否决权，但是的确有用处。注意，一次会议只能选择一个议题。」并确认乙醇要向议题②行使该权利。
- 大禾放话「我相信宪兵队的机枪会解决问题的」。蓝冷泉则献上另一套方案：私下承认条约、只宣布好的部分，「逼死共党以后，我们再宣布条约，然后投诚帝国」，把维护和平的功劳全部揽下、反指共党破坏和平；又说「哪怕是骗帝国呢？也需要走这一步」，先用条约「带来一代人的和平」。
- 蓝冷泉继续谈黑帮：惊虎帮是政府救过命的「个例」，而深黑军团是原星都人、黑帮区基本盘；建议宣布与深黑军团合作，「至于深黑军团说要反对帝国什么的，他们只是反对进盟而已，我们可以劝劝他们支持帝国」，并评价那群人「就是疯子，要把除了希联以外的人全杀光」「他们是不惜一切代价的，一切都可以成为代价」。
- 大禾道谢，小夫、大禾、蓝冷泉相继伸手：「我们团结起来吧！」「好，团结起来！」「为了国家！」——记者们听不到关麦后的谈话，只看到总裁们笑着互相握手；以往勾心斗角的财阀「从来没有像这样团结过」，在场许多人热泪盈眶，「祖国万岁！」成为这个名镜头的标题。
- 结算：乙醇因接受媒体采访、发言加分与名镜头加分获得城市声望 6；光胜公司因声望增长提升协调度 3；获得公司精神「民主栋梁！（协调+3）」；获得「光胜100%点心」若干。乙醇行动轮结束。

（七）千分线：救助站里的叶心

- 千分剧情线开始：千分获得《民主党会议记录》，「该记录中有部分信息缺省，怀疑是不可对公众宣布的内容」；叶心已预约与千分的会议。
- 千分来到天策科技公司的后院——曾经是叶宅，现在是救助站。他见到正在分发生活用品的叶心：头发凌乱，勉强对每个领物资的民众微笑，而那些民众「看起来已经营养不良了」。
- 叶心确认千分是为路絮的事而来，随后带他到偏僻小巷谈话：共产党之后也会召开大会，再之后开议会的大会；「我们把路絮的身体送进了能量球。这应该能保存她的灵魂一段时间」，但必须「等到奇点吞噬她之前想出办法」。
- 她感谢千分送来的会议记录（民主党媒体报道内容太不全，共产党与中立媒体不被允许进场），并给出共产党的对策：坚持物价和扶贫政策，反对并揭发青都条约，坚持复国军基层工作并揭露民主党阴谋，保护罢工权并与人民阵线继续对话深入合作，阻止反动的议会章程通过，反对黄色工会并揭发其与政府的交易；此外需与深黑军团谈判、揭发民主党的卖国阴谋。
- 叶心自述个人处境：辞退所有家仆，把房子捐给国家，个人资产不多，现住市政府；「我曾经也喜欢荣华富贵，但我遇到了一个从小到大就喜欢替人打抱不平的人」，此后便一直良心不安，「战争改变了很多事情。我不能只以良心衡量这个世界了」，「我失去享受的能力了……唯有为人民服务的理想能够让我暂时忘记痛苦」。
- 她对「人民群众」的坦白：「说实话，我不觉得存在一个大的人民群众。」所珍视的人有的支持民主党、有的支持深黑军团、有的在麻木中生活，因此只能「尽可能帮到更多的人」——「这条鱼在乎，那条鱼也在乎。」
- 她揭开最重的秘密：所谓防御工事、被说成用来催眠人民的防御工事，「……是地雷区。无穷无尽的，地雷。」进盟和帝国已经把青都逼上绝路，青都不再谋求对外贸易、也不谋求主动出击，「但是他们只要往前一步，必须付出没有止境的代价」；她也为青都做出了选择——封闭自己。
- 目前只剩走廊地带（与进盟、帝国、教团国的共同边境、非军事区）尚未布雷：布雷则彻底封闭、无法再支援教团国，但能获得安全。
- 千分表示效忠之意，叶心纠正：「没有人需要为我效忠，大家都叫我叶心同志。」「我只对共产主义理想效忠。」她伸手说「为了人民」，并承认「即便人民已然不复存在……但我们知道，人民总会取得共识的，只要我们不断努力」。
- 松手时千分发现手里多了一枚徽章。叶心流泪微笑：「这是路絮的纠察队徽章，镰刀和锤子，很简单的搭配。这段时间，希望您能为她保管。」
- 后半段叶心回应千分提出的方案：惊虎帮「并不都是坏人，只需要抓捕高层的恶劣分子，弄清楚他们的罪行，交由人民公审」，她已收集了一部分证据，之后转交；又叮嘱身为通雷帮帮主的千分「不要把牺牲自己的方案放在最前面」，若实施计划她会给协助。她也说到自己的转变：「曾经，我认为是我在驱使着大家实现伟大的事业……现在，我看到我认识的朋友都能够独当一面……这是大家自己的选择啊。我可以相信大家。」并评价千分的选择「能够让星都人更多地免于深黑军团」。
- 关于纪念：叶心提到「0083小队队长赫章，叶暝，频闪事件死难群众，星都战役死难群众……每个人的名字，都应该刻在石碑上。以后，我们应该建一个侵略战争受害者纪念馆。」存放路絮身体之处很机密，「是否进入那里是需要经过民主表决的」，党的基层组织对各自区域负责，「我们不能随意干涉，但可以给建议」。她以「再见。祝您万事顺利，千分同志」作别（致敬）。千分离去时，听到巷子里传来一首哼唱着的曲子。

七、关键决策点

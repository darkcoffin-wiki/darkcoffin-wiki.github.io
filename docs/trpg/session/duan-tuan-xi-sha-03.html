六、剧情摘要

（一）出发与三重天灾

鸣十二确认每辆车的灯光正常并配备声波机器，车队出发。余烬把沙漠的凶险平铺直叙后，接连降下三项考验：脱水（消耗物资或使用技能）、迷路（使用指南工具或追踪）、沙暴（过生存或受到 2d4 伤害）。川崎罗提议分散据点方案被现实打脸：「所以为什么没考虑我的方案……车队排成长龙的话就可以随时折返取水了」。他带春叶众单独开车找到一小片绿洲解了缺水；时崎试图靠沙虫踪迹指路未果；众人又学着空调跳「奶龙舞」避沙暴，但沙虫就藏在沙暴身后。

（二）沙虫遭遇与废墟

沙虫的威压被写成整片沙地活过来。因为已备好驱散手段，沙虫立即离开。随后车队驶入一片报废装甲车废墟：战车被开膛破肚、炮塔扭曲、炮管插进沙里；士兵残骸保持最后时刻的姿态。废墟边缘有依托战车残骸的小营地，一个女人站在战车上举望远镜死盯着女王沙虫。

（三）以实玛丽：讨伐队先锋连连长

她跳下战车、一瘸一拐跑来，开口便是「你们是总部的援军？你们终于来了！」。外形被细写：金属义肢以报废卡车悬架与液压杆改装、外覆沙虫次级鳞甲，脸上疤痕密集、一只眼被彻底破坏，长袍以至少三种沙虫鞣制皮拼接，肩背油布包裹的近三米鱼叉枪。她自报身份：

【“报告！我是沙虫讨伐队，先锋连连长！以实玛丽！”】
【“沙虫讨伐队，应到210人，实到1人！”】

川崎罗以「总部援军」蒙混，她立刻反问「这个组织？你们不是总部的？」——余烬提示她是职业军人，无法简单蒙混。时崎点出她身上有秘密，随后川崎罗按住她的手致歉、以「你能在沙虫袭击下独自活下来，的确是奇迹」收束怀疑。她松手并给出条件：「只要能够猎杀那头畜牲，只要能够碾碎该死的西沙人，你们就有价值！士兵们！你们现在也是沙虫讨伐队的成员了！」

（四）营地：全家福、报废无线电与家人

营地里有照片（一家三口全家福，折痕密布、人脸模糊）与一台报废但擦得一尘不染的无线电。她对着没有电源的无线电向空气汇报「报告总部！我已收到支援！」；林好检查后确认无法使用。她随后跳上破桌演讲，宣布今天向女王沙虫发起最后一击，并要求修复七门仍能使用的火炮。

（五）川崎罗的纸条与取信抉择

川崎罗递纸条，推断她与部队很可能来自光胜，并给出两条未必合并的路线：把她的头颅带给阿拉莎，或利用她对付村长那帮人；同时明确不建议直接配合她的命令。

（六）原绘登场与以实玛丽的记忆

原绘以心声联系鸣（此前已有「灵识的涌动」祝福），并直接出现在鸣身边而其他人无法发现；她自称这次仍是「同样的手法」，只能靠精神影响和借用众人身体观察。她窥探以实玛丽内心后判定：她与沙虫确实是敌人，且「那个沙虫和任何人都不是朋友，没有合作的可能」，建议先消灭沙虫。紧接着鸣眼前出现画面：被巨兽蹂躏过的高速公路、卡车残骸、被游击队员看管的司机与押运员，护林人收下「被霸凌的画家的包裹」，沙狂掐住嘀咕的司机喂给沙虫阴影——护林人斥其「要分得清谁是我们的朋友！谁是我们的敌人！」，沙狂回以「凡是给光胜工作的，都该死。」。KP 以断片式的自述补出她的创伤：女儿的鞋、丈夫的名字、医生说她「接受不了亲人的死亡，出现了妄想症」，她把仇恨归结到希共与人民阵线。原绘揶揄「有人想给自己树立正当性啊」，又对鸣笑说「我可是余烬先生的好伙伴呢。这种姿态我才喜欢。」，并叮嘱「和你的朋友说不要反悔。沙虫是所有人的敌人，它已经失去控制了。」

（七）女王沙虫战

KP 给出「重伤的女王沙虫」完整面板（生命 300-12d10 腹部、护甲 50-5d10 外壳、伤害 60-3d20 大嘴、近战束缚、酸性毒液减速、怒吼全体命中并召援、脱壳转 1000 生命并让以实玛丽进入狂暴、修复火炮可削减部位或造成额外伤害）。战前，沙虫盘踞的圆心有一具保持半站身姿的骸骨，一手抱小包、定位器铃声大作——那正是勇者小队的包裹。以实玛丽用鱼叉枪造成穿甲 50 伤害，战斗开始：第一轮女王伤害减为 28、众人先手；第二轮她再造成 50 穿甲伤害，女王张口选择目标，一名角色被嚼中濒死（鸣以「气沉丹田」应对，空调在此过程中成为鸣的血族眷属）；第三轮以实玛丽被瞄准，却一拳把沙虫大嘴打偏、毫发无损。

（八）车队当靶与以实玛丽的最后一击

时崎提出把车队开过来当靶子、川崎罗补上「还有声波机器」，方案定为远光灯全开、不拉手刹、声波机器放车上、弃车让汽车自行冲向沙虫。悬月与林好协助完成。车队成功吸引女王注意力后，以实玛丽高举鱼叉枪跳入女王大嘴，尸身如鞭炮炸开，被召来的沙虫长鸣退去。她从沙坑中起身，面孔「如蜡烛般融化」、独眼仍在燃烧，撬下鳞片贴在伤口上。侦查还发现她长袍下的身体几乎全被虫甲覆盖——「这到底是个人还是个沙虫？」

（九）复仇的宣告与战利品

她飞起一脚踢爆沙狂遗骸，对包裹不感兴趣，并把矛头延展到希共、人民阵线、叶心、红樱：

【“我，以实玛丽，以我的生命起誓，我会追猎你们，直到鲜血流干，直到骨头碎裂！哪怕在世界的尽头，你们也会听见我的怒吼！”】

KP 正在计算她对众人的好感值，她最终脱下长袍、留下奖励（沙暴弯刀、锈蚀机枪、沙虫皮甲、亚哈船长的后继者、女王的腺体），跌跌撞撞走向光胜园区。包裹里是一张可走西沙漠直通光胜园区的地图，和一个礼盒——礼盒中是歪歪扭扭的蜡笔画（小女孩和男人骑着沙虫）与一行小字：「沙叔叔生日快乐——阿拉莎」。「沙狂究竟是什么人？是滥杀无辜的极端派，还是温柔体贴的大叔叔？或许同马克思主义哲学说的一样，这些都是他」——KP 把武器打上 if 标签，声明不会在主世界线主动关注它们。

（十）声波防线漏洞、校车与 if 线

众人想起被取走的一个声波晶体导致高速公路上驱散沙虫的防线出现漏洞，而满载孩子们的校车已经开上公路。他们赶去修复路灯，林好把复制品装回缺少部件的路灯；孩子们唱着歌驶向园区，科学家们在校车上，无线电里却是以实玛丽的声音：「他们是公司的巡逻队，你们直接来正门吧。我叫以实玛丽，是大家的导游。孩子们，你们想听和沙虫战斗的故事吗？」

紧接着 KP 塞入一段标注为 if线 的录像：驾车失败，校车停在被打烂的公路上，师生死伤——「你们看见了那些科学家们，他们的尸体挤在一起，在生命的最后一刻护住了年龄最小的学生。」以实玛丽在孩子面前演讲埋下仇恨，鸣十三在被动过手脚的路灯前听伤亡报告，光胜大部队赶到，旁白判词是「仇恨永远不会停止，你们成功陷入了复仇的轮回」。

（十一）回到阿拉莎

众人决定掉头，带包裹回到服务区。林好提醒「这算什么……」式的顾虑后，川崎罗把包裹交给鸣，认为他是「那时候最清醒的人」。阿拉莎落泪后说：

【“沙叔叔……你是个刽子手……你也是个英雄……再见了”】

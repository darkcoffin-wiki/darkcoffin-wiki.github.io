“3号”（薇薇安）

蚀血教编号3号，自称薇薇安。任何人看到薇薇安都会认为此人美丽至极，是一位充满青春气息的少女，似乎一切美丽之物都与她相配。她是一位礼貌而友善的少女，喜欢和人分享她的所见所感——只要对方没成为她计划的绊脚石。她自居蚀血教的合作者，对蚀血教的安排有自己的判断。

一、详述

其语录为：“美是在下衡量万物的法则。”“我从未说过我是蚀血教的奴仆。我们是合作关系。”（《黑柩人物介绍新》）
其一，来历成谜。长老们对3号的大部分事情都保密，所以除了他们以外没有人知道3号到底是怎么来的——是0号那样的人造人，又或是1号那样由凡人变成的“转化者”。（轮次 85）
其二，容貌与“模因”。奇怪的是，即便你见过她，甚至能用相机记录她的样子，也难以准确描述她的样子。只能见证，不能形容——希联异常事务委员会认为，这是薇薇安操纵“模因”的能力。（《黑柩人物介绍新》）
其三，形象与穿搭。3号看起来是与1号年龄相仿的少女，与1号喜欢用黑红主色哥特装打扮自己不同，3号有许多穿搭，她的家中有着专门收纳她那上百套穿搭的房间，她穿的最多的是一套由俏皮贝雷帽、呢绒礼服和女式皮鞋组成的装扮，理由是“在尽可能节省精力的前提下，这套装扮能最大程度展现我的美。”（轮次 85）3号的人生宗旨即是“美”，她的言行全部围绕着“美”进行。（轮次 85）
其四，对杀人的态度。3号厌恶杀人，因为她认为“我从未见过美的杀戮”，除非某种杀戮能让她觉得美，否则她不会这么做。（轮次 85）她曾经目睹过蛛眼和蚀血教成员的遭遇战，认为蛛眼杀人的方式“与美能搭上关系了”，对其产生好奇。（轮次 85）
其五，“魅惑”与事实上的自由。3号精心地给蚀血教成员们营造了一副长老们还能操控她的幻觉，实际上她已经用自己“魅惑”的能力使长老们失去对她的控制，她事实上已经是自由人了，或许是整个蚀血教还在教内（除去0号）的唯一自由的人造血族。（轮次 85）与风薰所用的“魅惑”不同，3号的“魅惑”不侧重于精神控制，而侧重于使人“认可”自己，让人认为她的形态和生活方式是“美”的，从而不忍去打破。（轮次 85）由于3号的魅惑，蚀血教长老们都认为3号“就应该那么活”，将3号视为平等的合伙人，一般会带着需要通过非暴力方式解决的任务登门拜访，许诺她“美”的报酬。（轮次 97）
其六，“美之居”与旅行。3号无心参与各种教内事务，只是让长老们为她在门廊中立国建了一座小别墅，里面放上了她游历各国收集的“美物”，她将此处称为“美之居”。3号的爱好便是旅行，作为不同身份的“游人”周游各国，但不深度介入任何事情，而是在这个过程中记录和收集“美”。（轮次 85）
其七，与1号的争执。1号讥讽3号“比起我来说，你更像怪物”“搞不明白为什么有人会把花架子当饭吃”，3号只是坚持“你的美太单调，美是开放的”；这使3号成为第一个让1号感到“害怕”的人，1号开始拒绝主动接触3号。（轮次 85）1号忘记了自己的名字，想要找回，但每次都终归作罢；3号却说，“我也忘了自己的名字，所以我给自己取了个名字。自己为自己命名，这才是美。”（轮次 85）1号与3号关于“名字”的分歧由此确立。
其八，与14号。14号遇到了蚀血教，他对蚀血教的作为恨之入骨，但他意外地认识了3号。3号被14号注重仪式感的“美”所打动，决定帮他一把；在3号的协助下，14号被蚀血教看中并赋予血能成为人造血族。14号临走前找到了出走的13号的下落，并希望3号能协助他保护甚至收留13号，面对3号“你要保护那个丑东西干什么”的质疑，14号回到“他的内心很美”，最终3号答应帮14号留意13号。（轮次 93）
其九，与原绘。3号曾经与原绘有过一面之缘，称其正在策划的各个“完美生命”项目都不够美，“不美，怎么称得上完美生命呢？”（轮次 85）
其十，与高氏政权的交涉。5号被派往北沙后通过“灵魂操纵术”读取电影院大火案和五月四日惨案受害者的灵魂记忆，继而制造幻觉恐吓高领，取得了有效进展；3号接而被派去直接和高领交涉，高氏政权由此得知蚀血教存在，并接受其援助。（轮次 139）
其十一，对蚀血教的评价。3号对蚀血教的自述是：“哎呀，我的创造主啊。虽然您的手段卑劣下作，您想毁掉这世上许多的美，但您再怎么说也是美的一种，我倒也不考虑将您毁掉。而且，既然是我的创造主，自然对我有着创造之恩，我是应该帮帮您——不过，不美的事情我可不能做哦。”（轮次 98）
其十二，对蚀血教安排的评价与外部关系。人造血族，但性情稳定。自居蚀血教的合作者，对蚀血教的安排有自己的判断。从各长老和她的关系来看，似乎的确可以这么说。蚀血教的外交使节，几乎与她接触过的各种势力都能保持良好关系，哪怕仅仅以个人名义。自称热爱世界一切美丽，为美而生活。（《黑柩人物介绍新》）
其十三，“未来之眼”。在“尽毁”if线的楔子中，蛛眼偶遇了一个女子，发现此人身上有着和镜缘同样的现象——有时候蛛眼用读心术看不到对方的想法。两人聊的投缘，此人突然提出占卜，蛛眼便接受。此人在占卜时告诉她，“你将来会杀死你的父母……你会杀害所有亲友，你帮助过的，依赖的，被依赖的，你所珍视的一切……你会被世界厌恶……你会站在自己的对立面……你将毁灭。”蛛眼却看不到这一切在此人心中到底是如何，认为这只是此人出于恶意的诅咒，但蛛眼却能用读心术感受到对方的善意，这使她十分疑惑，便笑着说道，“怎么可能呢——我就算毁了自己也不会让这一切发生的。”此人只是摇摇头，笑而不语。此人便是蚀血教3号，以占星术师的打扮出现在蛛眼面前，依旧自称薇薇安。她事实上就是“未来之眼”的拥有者。（“三眼”中，镜缘掌握“过去之眼”，蛛眼掌握“此刻之眼”。）（轮次 162）
其十四，在1号结局中的一瞬。薇薇安在那场爆炸中呼唤了“曼陀罗”，冥冥中看到了1号的微笑，但那也许只是幻觉。（轮次 133）

报告总统大人，我是自然魔法组现任组长青昭。
希联世界之仪神秘学部门，自然魔法组现任组长。极其年轻。
她这一组此前一直被说成想得超前却从没做成过。然而演示会上她把投影魔法和启源量产的灵魂反应炉接在一起，做出了不需要施法者的闭环施法，即法天象地。
总统当场决定把试验场放到北沙。临走时他低声问她是不是北星都青家的人。她承认是，但自己不代表青家全体族人的意志。
总统认为，法天象地若能做成，就不必献祭星都去换护盾；而她相信自己能阻止 0 计划。总统的回答是，这就是献祭，若采用 0 计划，他会和星都共存亡。
她把总统留下的遗嘱交给镜缘，说如果自己无法再回来，请打开它。
星都战役后下落不明。
同时其实是教团国的第十三圣人。

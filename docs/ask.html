问一句

输入一句话，跨四个站一起找。结果会告诉你这句话在 设定集、花絮、 跑团记录 和 分析报告 里分别出现在哪。

检索下方还有一个 「用 AI 解释这个问题」：它会用你自己的 DeepSeek API key 阅读最相关的几条原文、再按资料回答一次（key 只存在本页会话里，关掉标签页即失效）。 这里只回答一次，不追问；想连续对话请去 黑柩问答。 AI 可能出错或遗漏，一切以链接到的原文为准。

怎么问比较好

  • 名词优先：只输入「希联」「北沙」「天使」「镜缘」这类词，命中率最高。
  • 不必写整句：写成自然语言也行，但系统是按关键词匹配的，长句的效果取决于里面有几个实体词。
  • 简称与全称都认：希联／希望联邦、进盟／进化者同盟、教团国／启示录教团国 等会互相当作同义词。
  • 想看原文就点结果——检索本身不生成内容，每个结果都指向 wiki 里的真实页面。
  • AI 问答：点检索结果下方的「用 AI 解释」，填入你自己的 DeepSeek API key， 它会读取 5 条最相关原文再作答，并给每个结论标注来源编号。回答仅供参考。
  • 想连续追问：这一页只解释一次；要像聊天一样多轮对话，去 黑柩问答。
